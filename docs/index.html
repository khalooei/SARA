Overview

The decision boundary is learned where the model is least certain

Deep networks are vulnerable to small input perturbations, and the samples near the decision boundary carry most of that risk. SARA revisits them while training. In every iteration it finds the misclassified and low-confidence samples of the mini-batch, moves each one to a nearby point that the current model classifies correctly with sufficient confidence and margin, and adds every successful correction to the batch. The correction follows a new loss, the Confidence Guard loss, and SARA works on top of standard training or of adversarial training.

Loss

Confidence Guard loss

A cross-entropy pull toward the true class plus a hinge penalty on the margin. It bounds the misclassification error and encodes the acceptance criterion exactly.

Integration

A plug-in for adversarial training

SARA wraps the base loss of standard training or of PGD, TRADES, MART and LSA adversarial training without changing it.

Robustness

Up to 16 points more robust accuracy

With per-method tuning, SARA improves the robust accuracy of every base method in every configuration tested on MNIST, CIFAR10 and SVHN.

Theory

A provable inner correction

The correction converges under a standard smoothness assumption, and every accepted sample certifies a robust neighborhood.

Scale

A class-count-relative threshold

The confidence threshold is set relative to chance level, ξ · 10 / C, so the acceptance criterion stays meaningful on CIFAR100 and Tiny-ImageNet-200.

Engineering

Batched and controllable

All challenging samples are corrected in one tensor operation, and a correction budget and a confidence cap address the instabilities analyzed in the paper.

Method

One training iteration

SARA adds an inner correction to each mini-batch and a second term to the training objective. Everything else in the training loop stays as it is.

Challenging setS = {(x, y) ∈ B : argmaxj fj(x) ≠ y or fy(x) < ξ}
Marginh(x, y) = maxj≠y fj(x) − fy(x)
Confidence Guard lossLCG(x, y) = CE(f(x), y) + λmargin · ReLU(h(x, y) + τ)
Inner updateδ ← ΠΔ(δ − α ∇δ LCG(x + δ, y)), Δ = {δ : ‖δ‖∞ ≤ ε, x + δ ∈ [0, 1]d}
Outer objectiveLossSARA = Lossbase(B) + LossCG(S*)

    Theory

    Guarantees behind the correction

    Proposition 1

    Convergence

    Every iterate stays in the admissible set. Under a standard smoothness assumption, the Confidence Guard loss decreases monotonically and the correction reaches an approximate stationary point at rate O(1/K).

    Proposition 2

    Consistency

    The Confidence Guard loss upper-bounds the misclassification indicator, and its two terms encode the confidence and margin conditions of the acceptance region exactly.

    Proposition 3

    Certified neighborhood

    Under the current model, an accepted sample is surrounded by a ball of radius min{r, τ / Lh} on which the prediction does not change.

    Interpretation

    Vicinal risk minimization

    The outer objective adds to the empirical risk a model-dependent vicinity that is concentrated near the decision boundary.

    Code

    Install and train

    The repository contains the method, the GAIRAT, FAT and OHEM baselines, the scripts of every experiment, and unit tests. MNIST, CIFAR10, CIFAR100 and SVHN download automatically.

    Command line 
    git clone https://github.com/khalooei/SARA.git
cd SARA && pip install -e .

python train.py --dataset mnist --model lenet \
    --base-loss pgd --sara --epochs 20 \
    --eval-apgd --out-dir runs/mnist/at_pgd_sara
    Python 
    from sara import SARAConfig, build_base_loss, sara_training_step

base_loss = build_base_loss("pgd")   # ce, pgd, trades, mart
cfg = SARAConfig(epsilon=0.2, tau=0.05, xi=0.5, kappa=10)

for x, y in train_loader:
    stats = sara_training_step(model, optimizer, x, y,
                               base_loss, cfg,
                               base_loss_kwargs={"pgd_steps": 7})
