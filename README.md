This repository provides the official implementation and supplementary materials for **Self-Adaptive Revisiting Awareness (SARA)**, a novel training strategy designed to improve both robustness and generalization in deep neural networks.  

SARA introduces the **Confidence Guard loss**, which adaptively identifies and refines challenging boundary samples during training. By dynamically augmenting mini-batches with corrected versions of low-confidence and misclassified samples, SARA ensures the model receives stronger supervision around decision boundaries, leading to enhanced performance against adversarial attacks and improved generalization on clean data.
